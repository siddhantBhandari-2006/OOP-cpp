## How to Compile and Run

1. Install a C++ compiler such as **MinGW-w64 (g++)**.
2. Open the repository folder in VS Code.
3. Open the terminal in the folder containing the `.cpp` file.
4. Compile and run a sample program:

```bash
g++ "OOP-C++/First.cpp" -o first
./first
```

On Windows PowerShell:

```powershell
g++ "OOP-C++/First.cpp" -o first.exe
.\first.exe
```

Replace the source filename with the program you want to execute. Keep quotation marks around paths or filenames containing spaces.

- Links point to source files in this repository and open the code directly on GitHub.
